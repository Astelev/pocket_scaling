# Just Scale It

аддон для мода Create: Pocket Sized уменьшающий производительность и объём уменьшенных механизмов а так же добавляющий интеграцию схематики с уменьшенными конструкциями.

Minecraft **1.21.1**, NeoForge **21.1.256+**, Create **6.0.10**, Create: Pocket Sized **0.24.1** (включает Pym **0.5.1**), Sable **2.0.6**.

## Возможности

- Чёрный список блоков и тегов: проверка при уменьшении и размещении на маленькой конструкции. По умолчанию запрещены производственные станки и предметные хранилища.
- SU: производство и потребление масштабируются по объёму; RPM остаются прежними.
- FE: масштабируются производство, потребление, буфер и скорость приёма/отдачи. Для нестандартных хранилищ нужен совместимый адаптер.
- Жидкости: масштабируется вместимость баков; расход топлива и единица mB не меняются.
- Стоимость уменьшения по группам блоков: по умолчанию вращающиеся механизмы требуют один точный механизм, остальные блоки бесплатны. Креатив освобождён. Платёж возвращается при неудаче операции.
- Схемы Create сохраняют и восстанавливают масштаб физических частей и клей Pocket; предпросмотр учитывает масштаб. Существующий путь восстановления — творческая установка схемы. Автоматическая постройка физических частей схемомётом не добавлена.

Мод не регистрирует предметы, блоки или вкладку креатива. Монтажного инструмента здесь нет. Buzzy Bees, GeoResonance, Nomad и AeroUtils для работы не нужны.

## Настройка

Файл мира: `serverconfig/just_scale_it-server.toml`. Настройки синхронизируются с клиентами.

- `pocket_balance.enabled`, `power_exponent`, `fluid_capacity_exponent`, `blacklist`.
- `shrink_cost.enabled`, `groups`.
- Формат группы: `имя|блоки и #теги через запятую|предмет оплаты|количество`. Первая совпавшая группа имеет приоритет; `@mechanical` охватывает механические блоки Create и аддонов, `*` — все блоки. Количество `0` освобождает группу от оплаты.

При размере 1/2 и показателе 3 мощность/буфер составляют 1/8 исходного значения. Лишняя энергия/жидкость при уменьшении теряется. Производственные рецепты, вместимость предметных инвентарей и расход топлива не масштабируются.

## Переход с AeroUtils

Старые версии AeroUtils уже содержат эти функции: совместная установка блокируется, чтобы избежать двойного масштабирования. Нужна версия AeroUtils **0.0.2+**, использующая Just Scale It как зависимость. Монтажный инструмент и поддержка строительства пчёлами остаются в AeroUtils.

Параметры `[pocket_balance]` и `[shrink_cost]` можно перенести из `aeroutils-common.toml` в соответствующие разделы нового серверного файла. Сохраняемые ключи схем `aeroutils_pocket` и FE `AeroutilsPocketFE` оставлены для совместимости существующих миров и схем.

## Сборка

Проект содержит Gradle Wrapper (`gradlew`, `gradlew.bat` и `gradle/wrapper`), настройки NeoForge, исходники и GitHub Actions. Установите JDK 21 и откройте корневую папку как Gradle-проект в IDE либо выполните:

```bash
git clone https://github.com/Astelev/pocket_scaling.git
cd pocket_scaling
./gradlew build
```

В Windows: `gradlew.bat build`. Отдельно устанавливать Gradle или вручную копировать JAR для компиляции не нужно. Результат: `build/libs/just_scale_it-0.1.0.jar` (файл `-sources.jar` предназначен для разработчиков).

Для игры установите обычные зависимости Pocket, в том числе Aeronautics/Simulated и Pehkui, согласно требованиям самого Pocket. Успешная сборка проверяет компиляцию и регрессии; полноценный запуск игры проверяется отдельно.

Java 21: `./gradlew build`. Все зависимости скачиваются через Maven; сторонние JAR не включаются в дистрибутив. GitHub Actions запускает сборку, регрессионные проверки SU/FE/жидкостей, правил оплаты и формата схем, а также проверяет точки Mixin по байткоду зависимостей. Результаты доступны в артефакте `just-scale-it`.

Для разработки зависимого мода: `./gradlew publishToMavenLocal`; координаты `net.aste.just_scale_it:just_scale_it:0.1.0`.

## API интеграции

`api.ShrinkCostExemption.enter()` даёт ограниченное синхронным `try-with-resources` освобождение от оплаты для доверенного строителя. Оно не обходит чёрный список. `api.BatteryDock` предоставляет адаптеру доступ к внутреннему буферу держателя батареи, не создавая зависимости от AeroUtils.
